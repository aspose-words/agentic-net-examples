## Repository Overview

The repository provides ready-to-run console samples that demonstrate how to use Aspose.Words for .NET across many scenarios. Each example is self-contained, builds on the documented API, and can be executed with minimal setup.

## What Makes These Examples Different

- Every published example is compiler- and runtime-validated before release.
- Each `.cs` file is a standalone console example with no hidden shared project.
- Category metadata records required packages, APIs, workflows, validation guidance, and known failure patterns.
- Root and category metadata are regenerated alongside examples from auditable run evidence.

## How to Use

To explore any feature, select the appropriate category, set up a temporary .NET console project, add the required NuGet packages, copy the example code, run it, and verify the produced output.

1. Identify the category that aligns with your document-processing requirement.
2. Examine the category README.md, AGENTS.md, and index.json to understand the available examples.
3. Create a temporary console project targeting the repository's .NET framework version.
4. Install Aspose.Words and any additional NuGet packages required by the chosen category.
5. Copy the chosen .cs file into the project as Program.cs.
6. Build and run the project, then verify the generated output files or console messages.
